# checkTriangle

This program checks what kind of triangle it is and finds the area.  
You can fill in the sides, or use the height or angle to calculate the area.

## What it can do
- Check if the sides can make a triangle  
- Tell the type:
  - Equilateral (all sides equal)
  - Isosceles (two sides equal)
  - Scalene (all sides different)
- Find the area by:
  - Using three sides  
  - Using base and height  
  - Using sides and angle  

## How to use
1. Open Google Sheets.
2. Click **Extensions → Apps Script**.
3. Paste the code from `checkTriangle.js`.
4. Type the side values in the sheet (E13–E18).
5. Run the function to see the triangle type and area.
